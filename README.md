# Hello World Python Function

This repository contains a simple Python implementation of a "Hello, World!" function.

## Usage

You can use the `hello_world` function in two ways:

1. Import and call the function in your Python code:
   ```python
   from hello_world import hello_world
   
   result = hello_world()  # Prints "Hello, World!" and returns the string
   ```

2. Run the module directly:
   ```bash
   python hello_world.py
   ```

## Testing

To run the tests:
```bash
python -m unittest test_hello_world.py
```
